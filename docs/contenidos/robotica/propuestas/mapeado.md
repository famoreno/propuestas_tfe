## Descripción

Este trabajo plantea la exploración exhaustiva de distintas metodologías de creación de mapas, localización y navegación con distintos sensores para robots móviles autónomos. Los sensores a considerar serán: láser 2D, láser 3D, cámaras de profundidad, cámaras estándar y sistemas inerciales.

Se pretende realizar una batería de pruebas para estudiar casos de uso, tipos de mapas generados, utilidad de los mismos, precisión, retos, etc.

La propuesta estará enfocada en la programación ROS2, usando Python y C++ y generando un ecosistema que permita replicar las pruebas de manera sencilla.

Se explorarán librerías como ORB-SLAM3, MOLA, FastLIO, VGGT, etc.

## Objetivos

- Estudio del estado del arte en implementaciones de sistemas de mapeado, navegación y localización.
- Integración de implementaciones en ROS2.
- Grabación de datasets en laboratorio con cada sensor.
- Generación de un banco de trabajo que permita realizar pruebas.
- Generación de informe comparativo de resultados.
